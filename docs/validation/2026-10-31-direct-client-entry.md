## 实现与取舍

- 新 `.lnk` 直接指向创建时由 MSIX 查询得到的官方 `app\ChatGPT.exe`，普通窗口，参数严格为 `--remote-debugging-port=19327 --remote-debugging-address=127.0.0.1`。本机官方程序 Authenticode 状态为 Valid。
- 伴随程序独立运行，Run 命令直接启动 Node 和 `src\main.mjs`，不使用隐藏 PowerShell 或执行策略覆盖。登录时可能显示控制台，关闭它会停止伴随程序。
- 新收据为 version 2，记录 executable；官方更新导致路径变化时拒绝复用旧入口，提示先 `shortcut.ps1 -Remove` 再创建。不会自动恢复旧版准备态为脚本入口；仍保护用户修改。
- 安装更新仅在实际启动项与收据匹配时迁移，保留首次安装前的原值；入口冲突时回滚本次启动项及安装收据。
- 普通快捷方式不再有脚本层面的普通实例提示。用户需先保存并完全退出普通实例，否则官方程序可能复用原实例而无法补开端口。没有自行退出当前工作聊天。
- 保留 `launch.ps1` 作为可选手动诊断工具；新日常快捷方式和 Run 项均不调用它。没有修改官方包、开发风味、完整性策略、火绒防护或信任区。
