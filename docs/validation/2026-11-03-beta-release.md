## 环境差异

新增测试首次使用宿主管理的临时目录时，Windows PowerShell 拒绝执行其中的未签名脚本。在相同权限和 `RemoteSigned` 策略下，同一最小脚本放到项目 `.cache/` 可执行，复制到宿主管理的临时目录即被拒绝；文件未见额外数据流。本记录不推断底层拦截机制。

测试改用与现有启动器测试一致的项目本地 `.cache/` 隔离目录，没有添加策略绕过参数。该结果不证明带互联网下载标记的 ZIP 能直接安装，下载标记与安全软件行为列入干净电脑待验收项。

## 审查与追溯

Standards 与 Spec 分别由只读审查者检查，以 `4fa8644` 为本任务固定基线。Standards 指出未跟踪文件会被误报为干净，已移除该排除参数；最终发布包要求 `sourceTreeDirty: false`。为保留根 README 中的主题构建能力，ZIP 同时包含工具源码。

增量审查指出自定义输出目录可能反过来影响工作区状态，已将源状态采集提前到创建输出目录之前。维护者打包/发布回归命令依赖 Git，应在源码仓库运行；解压包支持主题构建与校验，不承诺自我打包。

最终包从提交后的干净工作区构建，源提交和文件摘要以包内 `release-manifest.json` 为准；ZIP SHA-256 单独写入 `SHA256SUMS.txt`。二进制和本机构建收据均不提交 Git。
