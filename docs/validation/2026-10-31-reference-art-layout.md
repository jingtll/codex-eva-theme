# 人物与机体纹样对齐原版构图

## 已确认范围

用户对比 Codex 与 DeepSeek Harness 截图后，确认采用左侧大人物、右侧独立大代号图形。人物按比例缩放，底部位于输入框上方；绫波丽使用圆环，明日香使用多边形框。机体纹样允许延伸到现有面板背后，面板位置、尺寸和功能保持原状。窄窗口等比缩小，保留此前确认的深色红色加粗描边。

## 实现

- 人物从左下 300px / 400px 上限改为随工作台宽高等比缩放，宽窗口优先使用约九成可用高度；窄窗口受宽度限制，保留完整人物。
- 代号图形从左下共锚点改为右侧独立定位。复用本地参考插件 `dsh-plugin-eva-theme/lib/client.js` 的两套 600 × 600 SVG 图形，包含环线、多边形、编号与角色标记；图形最大画布宽度 680px，并受工作台宽高约束。
- 装饰仍受可见工作台裁剪，避开侧栏、宿主右侧内容区与输入区；图形位于仪表面板后方，不接收点击。
- 原角色 PNG 字节、面板规则、主题切换及背景强度设置未改动。

## 验证

- 浏览器回归先在旧布局失败：人物未达到大幅构图要求；调整后通过。
- 浏览器 9/9 通过，覆盖双主题、宽窄窗口、宿主侧面板开合、页面缩放、输入/审批命中、深色红线与卸载。
- 契约 95 项：94 通过、1 跳过、0 失败。跳过项为既有符号链接权限条件。默认沙箱下 Windows CIM 生命周期测试受限，使用获准的沙箱外运行后完整通过。
- 使用实际角色素材查看浅色宽窗和深色窄窗预览，其他两组预览同时生成。隔离截图保存在 `.cache/screenshots/reference-{light,dark}-{1800,560}.png`。
