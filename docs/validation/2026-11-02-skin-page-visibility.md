# 主页与设置页皮肤显示

## 范围与根因

皮肤在主聊天工作台（新建及已有聊天）与 Codex 设置页显示，图像等其他目的地隐藏。原有模态窗口避让继续生效。

原安装和窗口发现逻辑均依赖聊天输入框。首次修改只放宽安装条件，没有修改周期性窗口发现；设置页移除输入框后，隐藏渲染窗口中残留的输入框可能让伴随程序切走连接，从而卸载设置页皮肤。

现在安装和窗口发现均认可宿主的可见主内容区。皮肤根据设置页结构标记与侧栏当前目的地决定是否显示；隐藏页面释放注入的配色标记。窗口发现继续只接受原有已确认主页面目标，不扩大到内嵌网页或辅助窗口。

## 自动化验证

- `page-visibility.browser.mjs`：设置页无输入框直接安装；图像输入框不触发显示；图像、设置与聊天往返；模态窗口关闭不绕过页面限制。
- `target-selection.browser.mjs`：真实伴随程序、发现逻辑和会话链路运行；可见聊天替换为无输入框设置页后，经过至少四次发现轮询仍保持皮肤，隐藏窗口不接管。修改发现条件前，该断言失败，修改后通过。
- 本轮完整浏览器测试 12 项通过；窗口发现单元测试 11 项通过；`git diff --check` 通过。
- 前一阶段完整伴随程序测试 103 项通过、1 项 Windows 符号链接权限跳过；主题检查通过。发现条件补修后运行了上述相关单元测试与完整浏览器测试。
