# 深色人物描边可见度

## 用户确认的目标

用户截图反馈：深色状态下人物描边几乎看不清，要求加粗、加深红色。经本轮 grill 确认采用“饱和、偏深的 EVA 红，线条约加粗 1.5–2 倍，清晰可辨的干净线稿”。实现位于 `fix/dark-portrait-contrast`，依赖 `255afc2` 的可见工作台布局修复。根目录原主题草稿保持原样。

## 原因与修改

原始人物 PNG 是透明背景的近黑线稿；可见像素 RGB 通道仅 0–1。旧 CSS 只添加红色模糊阴影，原线条仍为黑色，并由默认背景强度 0.18 再次降低整体透明度，因此在深色背景上几乎无对比。

- 仅对深色明日香的图像 alpha 做轻微扩张（SVG `feMorphology` radius 0.75），再以 `#d9364b` 实际着色，不以光晕代替线条。
- 深色人物透明度为背景强度的 3.6 倍，最高 0.85；默认 0.18 对应约 0.65。背景强度归零仍隐藏人物。
- 浅色绫波丽保持原透明度和样式；人物位置、仪表、扫描线及机体纹样不因本次描边调整而增强。
- PNG 文件字节未改动，NOTICE 中素材哈希仍匹配。滤镜随自有 shadow root 一并销毁。
