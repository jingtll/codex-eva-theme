## 当前事实与证据边界

本机运行安装包版本 `26.1021.3705.0`；其 `package.json` 内部应用版本为 `26.1021.31345`，两者需分别记录。

只读检查确认：

1. 客户端使用 Electron，`resources/app.asar` 包含 `.vite/build/early-bootstrap.js`、主进程、preload 和 `webview/` 前端资源。
2. preload 设置 `document.documentElement.dataset.theme`，并通过 `electronBridge` 暴露 `getSystemThemeVariant` 和 `subscribeToSystemThemeVariant`。系统主题与用户手动选择可能不同，皮肤最终跟随页面实际生效的主题。
3. preload 将部分 IPC 消息转为页面 `message` 事件；同时存在通过 MessagePort 连接 app host 的路径。不能据此假设所有任务事件均出现在 `window.message` 中。
4. 前端代码处理 `turn/started`、`turn/completed`、审批及 token 用量通知。这证明宿主内部存在这些能力，不证明插件已获得订阅入口。
5. 本次尚未验证发行版外部调试连接、脚本注入、额度读取、声音播放和系统媒体控制。
6. `early-bootstrap.js` 中的 `CODEX_ELECTRON_CHROMIUM_SWITCHES` 处理受开发构建条件限制，不能把该环境变量当作生产发行版可用入口。这不等于已证明其他调试连接方式不可用。

## 技术路线

目标形态为**伴随程序＋页面皮肤＋本机媒体桥**。用户保持原来的 Codex 启动入口，由伴随程序自动接入。通过本机调试连接加载自有 CSS／JS 是待验证的候选方式，能否用于普通启动的发行版必须实测，尽量保留官方安装包原样。

优先验证不修改安装包的接入方式。若无法满足普通图标启动后的自动接入，用户已接受一次性的可恢复接入配置或客户端补丁；先明确修改范围和恢复方案，再实施。补丁可能受商店包写权限、完整性检查和更新覆盖影响，若无法形成可验证、可恢复的方案，应报告技术阻碍，不强行修改。

自建客户端的会话、审批和文件功能维护范围明显更大，不在本方案内。产品形态的选择与代价见 [ADR-0001](../../adr/0001-companion-with-reversible-integration.md)。

外部调试连接只是候选加载方式，尚未验证可用。实施第一步应在独立客户端实例或隔离测试环境验证目标识别、注入、重载及恢复。不得为实验结束正在工作的本次聊天；若现有单实例机制要求重启，交付诊断与操作入口，在合适的验收窗口执行。

### 启动与兼容适配

- 探测安装位置、包版本、内部版本和前端资源指纹，不硬编码当前带哈希的脚本名作为永久入口。
- 验证调试连接仅限本机，并限定到已确认的 Codex 主界面；不向浏览器、第三方网页、登录界面或插件 iframe 注入。
- 调试端点具有页面控制能力，应只在增强运行期间开放，避免将端点暴露到局域网。
- 伴随程序开机自动运行并驻留托盘，检测到 Codex 后自动接入。托盘提供暂停皮肤、设置和退出入口；退出后允许用户再次手动运行伴随程序，正常 Codex 启动方式保持不变。
- 伴随程序控制连接生命周期。断连时回收本机资源；重连避免重复挂载。Codex 未运行时停止额度和媒体轮询，保留必要的进程检测；检测具体实现与间隔由实施验证决定。
- 明确区分“连接成功”“皮肤加载成功”“宿主状态联动成功”，诊断输出不包含聊天内容和凭据。
- 未识别版本默认不启用脆弱的事件适配；报告兼容状态，不能静默使用上个版本的偏移或代码替换。
- 第一阶段若证明直接调试连接不可用，记录证据并评估用户已接受的可恢复接入配置或补丁；先完成具体修改与恢复设计，不直接改动当前运行客户端。不能自动扩大为自建客户端或不可恢复的修改。

### 页面皮肤

- 从参考插件迁移可复用的配色、线稿与 SVG 装饰，保留来源和许可说明。
- 以自有根节点挂载装饰和组件；主题 CSS 使用明确作用域，避免全局重置破坏宿主弹窗、菜单及第三方页面。
- 角色背景避让主要阅读区域，装饰不拦截输入；支持窄窗口、页面缩放、侧栏与右侧面板变化。
- 默认开启角色线稿、02／00 机体纹样、扫描线及仪表，强度尽量接近参考插件。背景强度与组件开关可调整，减少动态效果偏好仍优先生效。
- 跟随页面实际生效的明暗主题，切换时同步颜色、角色和声音，不重建全部组件。
- 时钟显示真实本机时间；音乐组件只在有真实媒体会话时出现。
- 显示设置提供组件开关、大小、背景强度、声音开关和试听，支持单项与全部重置。
- 设置只保存皮肤偏好，不覆盖用户其他 Codex 配置；沿用现有配色草稿时先核实实际导入行为。
- 尊重减少动态效果设置；卸载回收节点、样式、计时器、监听器、订阅及媒体连接。

### 宿主事件适配

- 为当前版本确认实际事件传递路径，优先被动订阅并保留宿主原有处理流程。
- 将宿主消息转换为最小状态：任务／轮次标识、开始、完成、失败、取消、待审核及额度窗口。
- 只对启用后的实时事件作出提醒；以任务和轮次标识去重，历史回放、重连快照及子任务不重复播放完成音。
- 正常完成才播放完成提示；失败或取消不得当作成功。待审核提醒在真正进入待审核状态时播放。
- 待审核和完成音默认开启，窗口在前台时也播放；提供总开关、分别开关和音量设置。
- 提示音覆盖所有主聊天，包括后台聊天；不因用户切换当前聊天而漏掉后台主任务完成事件。未获得事件订阅的会话范围须在兼容诊断中明确报告，不能宣称已覆盖。
- 多窗口时指定唯一提示音负责人，避免同一事件在多个窗口重复播报。
- 不用读取完整聊天文本、修改提交逻辑或绕开审批来获取状态。

### 剩余额度仪表

- 接入已登录客户端能够合法读取的账户额度信息；开发工具中的额度查询能力不等于最终用户安装后的读取能力，产品需验证独立可用的数据路径。
- 对每个实际返回的额度窗口分别展示名称、剩余百分比及重置时间；窗口长度、类型和数量由真实返回值决定，不硬编码为固定的两种周期。
- 默认同时展示主要额度窗口的剩余百分比及重置倒计时，展开查看详情。
- 对 `usedPercent` 使用 `clamp(100 - usedPercent, 0, 100)`。缺失或 null 表示不可用，不当作 0% 使用或 100% 剩余。
- 若存在多个额度桶，保留各桶含义，不把不同模型或资源的额度合成为一个百分比。
- 百分比不是剩余 token 数、余额或可执行任务数。仪表标明账户共享范围，不能标成当前聊天独享额度。
- 展示最近成功更新时间；失败时可保留旧值，但必须标明过期，不能伪装为实时数据。
- 首次加载与用户手动刷新时获取；前台可见时默认每五分钟刷新，后台暂停定时刷新。被限流时遵守服务端重试信息，不反复重试。
- 无可用数据路径时显示“暂不可用”，不读取或导出认证令牌，也不通过聊天调用模型来刷新额度。

### Windows 媒体桥与声音

- 参考现有 DSH 的 GSMTC 实现，通过 Windows 系统媒体接口读取当前会话，并提供播放／暂停、上一首、下一首。
- 桥接只接受明确的媒体动作，不开放任意 PowerShell 或 shell 执行。
- 若采用本机 HTTP／WebSocket 传输，需本机绑定、会话鉴权和来源验证；先验证客户端 CSP 是否允许所选传输及媒体资源，不能直接全局放宽 CSP。
- 媒体命令串行执行，返回结果校准界面状态；没有会话或读取失败时隐藏播放器。
- 音频仅使用用户可合法使用的素材，保留参考项目的素材权利说明。提供静音及试听，播放失败不影响聊天。

## 安装、更新与卸载

本机安装内容包含伴随程序、版本适配表、皮肤资源和必要媒体桥。用户继续从原来的 Codex 图标启动，伴随程序自动接入。专属 EVA 启动入口不作为日常使用要求；普通启动后的可用连接方式必须先验证。

安装先诊断兼容性，只有通过检查的版本才激活。加载失败应给出明确诊断并保留原客户端可用性；增强模式故障不能导致用户丢失会话。

卸载移除自有开机启动项、托盘入口、偏好与运行资源，关闭自有连接和进程，清理页面挂载，不删除 Codex 会话、凭据和用户项目。若采用文件补丁，修改前记录目标版本及原文件哈希、保存可校验备份，设计原子替换和失败恢复；卸载或恢复前校验目标是否仍为本程序修改后的版本，避免将备份覆盖到更新后的客户端。

## 实施顺序与验收

1. **入口验证**：发行版连接、自有最小节点加载、刷新后恢复、目标隔离、干净卸载；任一关键能力不成立则停止扩展并重审路线。
2. **双角色工作台**：配色、背景、时钟、显示设置；验收明暗切换、缩放、窄窗口、右侧面板和弹窗，不遮挡输入及审批操作。
3. **状态与原生集成**：验证额度读取、任务与审批事件，接入媒体桥和提示音。确认失败、取消、历史、重连、子任务、多窗口不误报。
4. **打包与恢复**：兼容诊断、安装升级卸载、普通启动回退、文档及资源许可。

测试分成契约测试、隔离浏览器测试、Windows 桥接测试和真实 Codex 验收；报告分别记录，不能相互替代。纯静态预览不算完整体验交付。
