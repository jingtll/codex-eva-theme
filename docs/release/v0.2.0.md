# v0.2.0 — Codex 更新后的本地自动兼容

本版本新增本地能力检测，让资源指纹变化时仍能尝试加载皮肤，并分别判断额度和提醒是否可用。

## 变化

- 未知指纹进入运行时检测，外观不再因版本门禁整体停用。
- 用只读额度请求的对应响应确认消息通道；额度格式异常时暂停显示。
- 提醒逐条检查方法、字段、聊天来源与完成状态，未确认通道或元数据读取失败时保持静默。
- 能力缓存只保存指纹、时间和布尔状态，最多 8 个版本、有效期 7 天；缓存不绕过消息校验，卸载会清理。
- 托盘分别显示外观、额度和事件状态。包含 11 月 4 日 Codex 更新适配。

## 下载和升级

下载 `codex-eva-theme-v0.2.0-windows.zip` 与 `SHA256SUMS.txt`，核对 SHA-256 后完整解压，按包内 `QUICKSTART.md` 配置入口。保留原有个人设置；升级前从托盘退出旧伴随程序，避免旧实例继续运行。不要只替换启动器 EXE。

需要 Windows 10/11、官方 Codex MSIX 客户端、Node.js 22+、Windows PowerShell 5.1 和系统 .NET Framework C# 编译器。无需 npm install，Node.js 和预编译启动器不随包提供。普通模式运行的 Codex 仍需保存工作后完全退出，再从 EVA 入口打开。

## 验证与边界

自动能力检测不是对未来所有版本的兼容保证：调试接入、界面结构或内部协议实质变化时仍需维护。未知版本路径由真实浏览器夹具覆盖；真实全部事件、媒体、额度精度、干净电脑安装与升级仍未全面验收。

实现与验证见 [本地自动兼容记录](https://github.com/jingtll/codex-eva-theme/blob/v0.2.0/docs/validation/2026-11-04-local-auto-compatibility.md)。发布归档包含准确源提交与文件摘要，不包含本机设置、安装收据、日志、缓存或聊天数据。
