## 功能与使用

深色明日香、浅色绫波丽；聊天工作台与设置页皮肤、仪表、媒体控制及角色提示音。完整皮肤需要 Windows 10/11、官方 Codex MSIX 客户端、Node.js 22+、Windows PowerShell 5.1 与 .NET Framework 编译器。

完整解压 ZIP，按 `QUICKSTART.md` 创建桌面 `Codex EVA` 快捷方式。点击入口同时启动伴随程序和官方 Codex，不依赖登录自启。该 EXE 是启动入口，不能独立分发。

本版本包含工作台定位、深色线稿笔触和聊天/设置页可见性的四个依赖修复。内部客户端 `26.1027.30824` 有历史验证记录；运行时以资源指纹检查兼容性，其他版本及未来升级未经承诺。
