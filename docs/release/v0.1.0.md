# v0.1.0 — Codex EVA Theme Windows 正式版

首个正式发布版本，面向官方 Codex 的 EVA 双角色主题与独立 Windows 伴随程序。二次开发于 [seaison/dsh-plugin-eva-theme](https://github.com/seaison/dsh-plugin-eva-theme)，针对 Codex 与 Windows 启动、页面和系统媒体接口适配。

## 功能

- 深色明日香、浅色绫波丽；角色线稿、机体纹样、时钟、额度仪表与角色提示音。
- 新建/已有聊天工作台及设置页显示皮肤，图像等页面隐藏。
- 点击 Codex EVA 快捷方式同时启动伴随程序与官方客户端，不依赖登录自启；已有普通模式实例时提示自行保存退出。
- Windows 系统媒体控制及显示、背景、缩放和声音选项；数据与事件能力以实际客户端兼容情况为准。
- 包含全部工作台定位、线稿笔触与页面可见性修复，以及真实客户端实图与中文安装/升级/卸载说明。

## 下载与使用

下载 `codex-eva-theme-v0.1.0-windows.zip` 与 `SHA256SUMS.txt`。完整解压至当前用户可写、准备长期保留的目录，核对 SHA-256 后，按照 `QUICKSTART.md` 配置快捷方式。

完整皮肤需要 Windows 10/11、已安装的官方 Codex MSIX 客户端、Node.js 22+、Windows PowerShell 5.1 和 Windows 自带的 .NET Framework C# 编译器。无需 npm install，包内未集成 Node.js 或预编译 EXE，首次配置从源码编译启动器。不要单独复制启动器使用。

`release-manifest.json` 记录准确源提交、工作区状态和逐文件摘要。包内排除用户设置、快捷方式、安装收据、日志、缓存和本地参考副本。单独使用配色可直接导入 `share/` 分享串。

干净电脑安装、真实升级/卸载与 Windows 重启、真实媒体/额度/提醒、桌宠兼容性和安全软件接受度仍需进一步验收。正式版标识表示维护者选择公开分发，不扩大已验证范围。
